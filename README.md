
# Research and Build Your Regional Bloom Plan — Stage 2 V1

A four-step accessible research-and-planning activity:

1. Define garden context.
2. Learn a source hierarchy and research process.
3. Research up to 10 candidate plants.
4. Select 6–8 and build a regional bloom plan.

## Accessibility features
- Semantic labels, fieldsets, tables, buttons, and native controls.
- Full keyboard operation; no drag-and-drop.
- Visible focus indicators.
- 44px minimum button height.
- aria-live step/download announcements.
- Visual timeline duplicated in a semantic text table.
- Downloadable UTF-8 text plan.
- No color-only state communication.
- Responsive layout.

Designed toward WCAG 2.2 AA; not formally audited.
